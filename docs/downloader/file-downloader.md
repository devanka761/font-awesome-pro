# File Downloader

Download any assets from url

**Example Headers through TypeScript Fetch**:

```typescript
{
  "Accept": String,
  "Accept-Language": String,
  "Connection": String
  "Content-Type": String
  "Sec-Fetch-Dest": String
  "Sec-Fetch-User": String
  "sec-ch-ua": String
  "sec-ch-ua-mobile": String
  "sec-ch-ua-platform": String
}
```
